**My tickets** (in the sidebar) lists every event you've registered for, so you never lose track of what's coming up.

## What you'll see

Events are grouped into two sections:

- **Upcoming** — events that haven't started yet, sorted by date.
- **Past & cancelled** — events that already happened, plus any that were cancelled by the host.

Each entry shows the event name, date and time, and a status badge:

| Badge | What it means |
| --- | --- |
| **Going** | Your spot is confirmed. |
| **Waitlisted** | The event is full; you're in line for the next open spot. |
| **Cancelled** | The host cancelled the event. |

Click any entry to open the full event page — that's where you'll find the venue details or, for online events, the meeting link once you're confirmed.

## If a host cancels an event

The event moves to **Past & cancelled** with a red **Cancelled** badge. Since Gatherly doesn't send emails, this badge is how you'll know — it's worth glancing at My tickets before heading out to an event.

## Removing an event from My tickets

Cancel your registration from the event page and the event disappears from the list. See [Register for an event](/guests/register).
