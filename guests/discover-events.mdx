The **Explore** page is where you find things to attend. It lists every upcoming public event, soonest first. It's also your home page whenever you sign in.

## Browse the list

Each event card shows the essentials at a glance:

- Title and cover image
- Date and start time
- Whether it's in person (with the venue) or online
- How many guests are going

Click any card to open the full event page.

## Search by name

Use the search box at the top of Explore to filter events by title as you type. Clear the box to see the full list again.

## Filter by format

Next to the search box you can narrow the list to:

- **All** — everything
- **In person** — events with a physical venue
- **Online** — events you join via a meeting link

## What appears on Explore

Explore shows events that are:

- **Published** by their host (drafts never appear)
- **Public** — private events don't appear here; you can only reach those through a link the host shares with you
- **Upcoming or recently started** — past events drop off the list

<Tip>
  Got a link to an event that isn't on Explore? That's a private event. Just open the link — you can view it and register the same way. See [Register for an event](/guests/register).
</Tip>
