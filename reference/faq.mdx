## For everyone

<AccordionGroup>
  <Accordion title="Does Gathere cost anything?">
    No. Every event on Gathere is free to attend, and hosting is free too. There are no paid tickets and no payment details anywhere.
  </Accordion>

  <Accordion title="Do I get email confirmations or reminders?">
    No — Gathere doesn't send emails. Your tickets live in **My tickets**, and that's also where you'll see status changes (like being promoted from the waitlist or an event being cancelled). Check it before heading to an event.
  </Accordion>

  <Accordion title="Can one account both host and attend events?">
    Yes. Every account can do both — host your own events from the Dashboard and register for others from Explore.
  </Accordion>
</AccordionGroup>

## For guests

<AccordionGroup>
  <Accordion title="Why can't I see the meeting link for an online event?">
    The link is only shown to confirmed guests. If you haven't registered, register first. If you're **Waitlisted**, the link appears as soon as you're promoted to **Going**. And make sure you're signed in with the account you registered with.
  </Accordion>

  <Accordion title="Why did my status change from Waitlisted to Going?">
    A confirmed guest cancelled, and you were first in line — so you were promoted automatically. You now have a confirmed spot.
  </Accordion>

  <Accordion title="I cancelled by mistake. Can I get my spot back?">
    Register again from the event page. If the event filled up in the meantime, you'll join the back of the waitlist.
  </Accordion>

  <Accordion title="Why isn't an event showing on Explore?">
    Explore only shows **published, public, upcoming** events. Private events are reachable only through their shared link, drafts are invisible, and past events drop off the list.
  </Accordion>

  <Accordion title="How do I know if an event was cancelled?">
    The event shows a red **Cancelled** badge — both on its page and in **My tickets** under Past & cancelled.
  </Accordion>
</AccordionGroup>

## For hosts

<AccordionGroup>
  <Accordion title="Can I edit an event after publishing it?">
    Yes — open it from the Dashboard, click **Edit**, and save. Changes appear to guests immediately, but nobody is notified automatically, so announce big changes (like a new date) yourself.
  </Accordion>

  <Accordion title="What's the difference between a draft and a private event?">
    A **draft** is invisible to everyone but you — nobody can register. A **private event** is live and open for registration; it's just hidden from Explore, so only people with the link can find it.
  </Accordion>

  <Accordion title="Do I have to manage the waitlist myself?">
    No. When a confirmed guest cancels, the first waitlisted guest is promoted automatically. Your Dashboard counts update on their own.
  </Accordion>

  <Accordion title="Can I undo cancelling an event?">
    Not from the app — cancellation is final. If the event is back on, create a new event and share the new link with your guests.
  </Accordion>

  <Accordion title="Can I see who cancelled their registration?">
    No — the guest list only shows active registrations (confirmed and waitlisted).
  </Accordion>
</AccordionGroup>
