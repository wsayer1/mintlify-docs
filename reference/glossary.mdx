---
title: "Glossary"
description: "The exact terms Gathere uses, in one place."
---

| Term | Meaning |
| --- | --- |
| **Event** | A gathering with a date, time, and location — either in person or online. All events on Gathere are free. |
| **Host** | The person who created an event. Hosts publish, edit, share, and manage their events and guest lists. |
| **Guest** | Someone who registers to attend an event. |
| **Register** | Reserve your spot at an event. One click — no payment, ever. |
| **Explore** | The page listing all upcoming public events. The home page for signed-in users. |
| **My tickets** | Your list of every event you've registered for, with your status for each. |
| **Dashboard** | A host's list of their own events — upcoming, drafts, and past — with guest counts. |
| **Going** | Your registration is confirmed; you have a spot. |
| **Waitlisted** | The event is full; you're in line and promoted automatically when a spot opens. |
| **Draft** | An event that's saved but not published. Only the host can see it. |
| **Published** | An event that's live. Guests can view it and register. |
| **Public event** | Appears on Explore for anyone to discover. |
| **Private event** | Hidden from Explore; reachable only through its shared link. |
| **Capacity** | The maximum number of confirmed guests. Once reached, new registrations join the waitlist. |
| **Check-in** | The host marking a guest as arrived on event day, from the manage page. |
| **Meeting link** | The video-call link for an online event. Visible only to the host and confirmed guests. |
| **Cancelled** | Either a guest cancelled their registration, or a host cancelled the whole event — context makes it clear which. |
