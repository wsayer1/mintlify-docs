The **Dashboard** (in the sidebar) is home base for hosting. It lists every event you've created, grouped by where it is in its life:

- **Upcoming** — published events that haven't started yet.
- **Drafts** — events you've saved but not published. Only you can see these.
- **Past** — published events whose start time has passed.

Each event shows its date, a status badge (**Upcoming**, **Draft**, **Past**, or **Cancelled**), and its guest counts — how many are confirmed and how many are waitlisted.

## From the Dashboard you can

- **Open an event's manage page** — click the event to see its guest list, check people in, copy the share link, or cancel it. See [Guest list and check-in](/hosts/guest-list-and-check-in).
- **Finish a draft** — open it, complete the details, and click **Publish event**.
- **Create a new event** — the **Create event** button is right at the top.

## Event statuses explained

| Badge | Meaning |
| --- | --- |
| **Upcoming** | Published and starting in the future. Guests can register. |
| **Draft** | Saved but not published. Invisible to guests, not on Explore. |
| **Past** | The start time has passed. Registration is closed. |
| **Cancelled** | You cancelled it. Guests see a Cancelled badge on the event and their tickets. |
